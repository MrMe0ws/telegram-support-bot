# Релиз 2.1.0

## Вариант для GitHub Releases

## 🚀 Новое

- **ИИ отвечает клиентам сам (Google Gemini).** По вашей базе знаний и данным подписки из Remnawave: статус, срок, трафик, лимит устройств. Работает и в Telegram, и в тикетах из web-кабинета. По умолчанию выключено — включается в `.env`: `AI_ENABLED=true` и ключ `AI_API_KEY` из Google AI Studio, бесплатного тарифа хватает для старта. Из России к Gemini нужен прокси — `AI_PROXY_URL`.
- **Два режима.** `AI_MODE=auto` — ответ сразу уходит клиенту, копия с пометкой 🤖 — в тему. `AI_MODE=draft` — в тему приходит черновик с кнопками «Отправить» / «Не отправлять», клиенту ничего не уходит без админа.
- **Отвечает как человек в чате.** Ждёт `AI_REPLY_DELAY_SEC` секунд тишины (по умолчанию 20), чтобы ответить на несколько сообщений разом, — клиент в это время видит «печатает…». Текст оформлен под канал: в Telegram — жирный, списки и ссылки, в кабинете — простой текст с переносами.
- **База знаний — обычные `.md`-файлы** в папке `knowledge/`. Тон, длину ответов и эмодзи задаёт `knowledge/00-стиль.md`. Правки подхватываются без перезапуска. В репозитории лежит рабочий пример — замените его своими текстами.
- **Зовёт человека, когда нужно.** Нет ответа в базе, вопрос про деньги или возврат, клиент недоволен или просит оператора — ИИ передаёт тикет, и в теме появляется «🙋 Нужен человек» с причиной и сутью. У клиента под ответами ИИ есть кнопка «🙋 Позвать человека»; `AI_HUMAN_BUTTON_FROM` задаёт, с какого ответа её показывать (`0` — не показывать). Сотрудник написал в теме — ИИ в этом тикете замолкает; вернуть — `/ai on`, выключить — `/ai off`. После `AI_MAX_REPLIES_PER_TICKET` ответов (по умолчанию 15) тикет уходит людям.
- **Смотрит скриншоты и слушает голосовые.** В Telegram-тикетах ИИ сам видит фото, слушает голосовые и аудио, читает PDF и текстовые логи. Видео и кружки передаёт человеку. Выключить — `AI_MEDIA=false`, предел размера файла — `AI_MEDIA_MAX_MB` (по умолчанию 10).
- **Запасная модель.** Если основная упёрлась в лимит бесплатного тарифа или перегружена, бот повторяет запрос через `AI_FALLBACK_MODEL` (по умолчанию `gemini-3.5-flash-lite`).
- **Что уходит в Google:** сообщения тикета, вложения и справка о подписке — ссылка подписки не передаётся. На бесплатном тарифе Google может использовать запросы для улучшения своих моделей.
- **Значок темы «ждёт человека».** Темы, где клиенту должен ответить сотрудник, помечаются ❗ — их видно прямо в списке тем. Ответили клиенту — значок возвращается к обычному. Работает и без ИИ: тогда ❗ стоит на каждой теме, где клиент ждёт ответа. Другой значок — `TOPIC_ICON_EMOJI_WAITING` (эмодзи из набора значков тем), пустое значение — выключить.

## 🐛 Исправления

- **`/profile` показывает профиль магазина**, если у клиента в панели несколько профилей на один Telegram ID (например, ещё и ручной тестовый). Раньше бот брал первый попавшийся.

## ⚠️ При обновлении

- Обновите код и пересоберите контейнер: `git pull`, затем `docker compose up -d --build`. База обновится сама при старте.
- Значок ❗ на темах включается сразу после обновления. Не нужен — задайте `TOPIC_ICON_EMOJI_WAITING=` (пусто).
- Если вы правили `docker-compose.yml` под себя и хотите ИИ — добавьте том базы знаний `./knowledge:/app/knowledge:ro`.
