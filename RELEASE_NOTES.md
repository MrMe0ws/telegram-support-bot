# Релиз 2.4.0

## Вариант для GitHub Releases

## 🚀 Новое

- **«Печатает…» в чате кабинета.** Когда клиент пишет в поддержку из веб-кабинета магазина, а ИИ работает в режиме «Авто», клиент видит под заголовком чата «печатает» с анимированными точками — пока ИИ выжидает паузу и готовит ответ, как в Telegram. С приходом ответа статус пропадает. В режиме «Черновики» статус не показывается: ответ уходит только после админа.

## ⚠️ При обновлении

- **Порядок важен: сначала обновите магазин (Remnawave Telegram Shop) до 5.21.0, потом саппорт-бот.** Магазин старее 5.21.0 событие «печатает» не понимает — бот работает как раньше, но статус в кабинете не появится.
- Обновите код и пересоберите контейнер: `git pull`, затем `docker compose up -d --build`.
