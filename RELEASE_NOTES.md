# Релиз 2.2.0

## Вариант для GitHub Releases

## ✨ Улучшения

- **ИИ отвечает только по теме сервиса.** На посторонние вопросы («Китай — страна или город?», просьбы написать текст, поболтать) ИИ больше не отвечает по существу, а одной фразой говорит, что помогает только с VPN и подпиской. На приветствие, «???» или набор букв коротко спрашивает, чем помочь, вместо «не нашёл в базе знаний». Тикет человеку из-за такого не передаёт. Вопросы, связанные с VPN, даже общие («работает ли VPN в Китае»), он по-прежнему разбирает.
- **Значок ❗ «ждёт человека» больше не мигает.** После первого ответа сотрудника значок до закрытия тикета не ставится — новые сообщения клиента не гоняют его туда-обратно.
- **Нет спама «бот изменил значок темы».** Бот сам удаляет эти служебные уведомления из группы поддержки. Нужно право бота «Удаление сообщений».
- **Пример базы знаний дополнен.** Раздел про компьютер: прямые ссылки на INCY под Windows, Mac (Apple и Intel) и Linux и разбор «установщик не открывается» — ИИ сначала сам уточняет систему и даёт правильный файл, а не сразу зовёт человека. Ещё кейсы: «что такое подписка» после установки приложения, лаги при общей подписке. Если у вас своя база — можно взять эти разделы за образец.

## ⚠️ При обновлении

- Обновите код и пересоберите контейнер: `git pull`, затем `docker compose up -d --build`. База обновится сама при старте.
- Чтобы бот удалял уведомления о смене значка темы, дайте ему в группе поддержки право «Удаление сообщений». Без него всё работает, уведомления просто остаются.
