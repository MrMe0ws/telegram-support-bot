# Релиз 2.3.0

## Вариант для GitHub Releases

## 🚀 Новое

- **Настройки бота прямо в Telegram.** В админ-панели появился пункт **«⚙️ Настройки»**: большую часть настроек теперь можно менять кнопками, без правки `.env` и без перезапуска. Изменения действуют сразу и сохраняются после перезапуска. Изменённое в боте помечено ✏️, а кнопка «↩️ Как в .env» возвращает значение из `.env`. Адреса, токены и ключи API в боте не вводятся — только в `.env`.
  - **🤖 ИИ-помощник** — включить или выключить ИИ для всех тикетов, режим «Авто» / «Черновики», основная и резервные модели, пауза перед ответом, сколько раз ИИ отвечает в одном тикете, сколько сообщений истории видит, фото и файлы (вкл/выкл и размер), с какого ответа показывать «Позвать человека», подпись ответов.
  - **🧪 Проверить ИИ** — тестовый запрос ко всем моделям сразу: какая отвечает и за сколько секунд, что не так с остальными, идёт ли связь через прокси и какая модель сейчас ответит клиенту.
  - **🎫 Тикеты и темы** — шаблон названия темы с примером и значки «открыт», «закрыт», «ждёт человека»: выбираются из набора значков Telegram, ID искать не нужно.
  - **💬 Тексты для клиентов** — приветствие, просьба описать вопрос, «обращение принято», «обращение закрыто», текст для заблокированных. Форматирование Telegram в присланном тексте сохраняется, а перед сохранением бот показывает, как текст увидит клиент.
  - **🔗 Интеграции** — включить или выключить Remnawave и проверить связь с панелью, часовой пояс дат.
  - **🛠 Система** — время работы, число открытых тикетов, уровень логов и «♻️ Сбросить всё к .env».
- **ИИ на выбор: Gemini, OpenAI или Claude.** Можно подключить одного провайдера или сразу нескольких — ключ на каждого: `GEMINI_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`. Провайдер определяется по имени модели (`gemini-…`, `gpt-…`, `claude-…`). Голосовые сообщения слушает только Gemini; фото, PDF и текстовые файлы понимают все.
- **Цепочка резервных моделей.** `AI_FALLBACK_MODELS` — резервные модели через запятую, по порядку. Если модель не ответила (лимит, перегрузка, сбой, нет связи), вопрос уходит следующей, в том числе модели другого провайдера. Не ответила ни одна — в тему приходит предупреждение, как раньше.

## ✨ Улучшения

- **Резервная модель подхватывает при любом сбое**, а не только при лимите запросов или перегрузке.
- **Команда `/ai` в теме** при выключенном ИИ подсказывает, где его включить.

## ⚠️ При обновлении

- Обновите код и пересоберите контейнер: `git pull`, затем `docker compose up -d --build`. База обновится сама при старте.
- Старые настройки работают как раньше: `AI_API_KEY` — ключ провайдера из `AI_PROVIDER` (по умолчанию Gemini), `AI_FALLBACK_MODEL` — то же, что `AI_FALLBACK_MODELS`.
- Значение, изменённое в боте (✏️), важнее `.env`. Если правите `.env`, а изменений не видно — нажмите у этой настройки «↩️ Как в .env».
